# Робот в хлеву — панель мониторинга (Arduino → ПК)

Проект читает данные с Arduino по USB‑Serial и показывает **простую “фермерскую” панель**: освещённость, огонь/дым и наклон (акселерометр).  
Графики вынесены в отдельную вкладку, основной упор — **информирование и тревоги**.

## Что уже реализовано
- **Сводка (главный экран)**:
  - крупные индикаторы: **Освещённость (L)**, **Огонь/дым (F)**, **Наклон (Y/Z)**  
  - баннер состояния: **НОРМА / ПОЖАРНАЯ ТРЕВОГА / НЕТ ДАННЫХ**
  - блок **«Что делать сейчас»** (подсказки)
  - журнал событий
  - тумблер **«ОХРАНА»** по наклону (реакция на изменение Y/Z относительно “нормы”)
- **Графики**: отдельная вкладка
- **История 24ч / 7д**:
  - данные пишутся в `data_logs/sensors_YYYY-MM-DD.csv`
  - вкладка `История` умеет загрузить последние 24 часа или 7 дней

## Структура
- `sketch_apr27b/sketch_apr27b.ino` — Arduino‑скетч (отдаёт данные в Serial)
- `qt_serial_dashboard.py` — приложение PyQt6 + pyqtgraph (основной UI)
- `plot_light_channel.py` — старый/простой пример на matplotlib (не обязателен)
- `requirements.txt` — зависимости Python

## Формат данных (Serial)
Скетч отправляет строки вида:

`L:<число> <статус> | F:<число> <статус> | X:<число> Y:<число> Z:<число>`

Например:

`L:512 NORM | F:120 SAFE | X:2 Y:-1 Z:0`

В приложении **X игнорируется** (по запросу), используется только **Y/Z**.

## Подключение
- Arduino подключается к ПК по USB.
- Скорость порта: **9600** (как в скетче).
- На Windows порт выглядит как `COM7`, `COM8` и т.д.

Важно: **Serial Monitor / Serial Plotter** в Arduino IDE должен быть **закрыт**, иначе COM‑порт будет занят.

## Установка (ПК)
Из корня проекта:

```bash
py -m pip install -r requirements.txt
```

## Запуск панели
1) Открой `qt_serial_dashboard.py` и выставь свой порт:

- `PORT = "COM7"`

2) Запусти:

```bash
py qt_serial_dashboard.py
```

## Логика тревог (по умолчанию)
Настройки находятся в `qt_serial_dashboard.py` (вверху файла).

### Огонь/дым (F)
- Если `F > 250` держится **≥ 2 секунд** → **ПОЖАРНАЯ ТРЕВОГА**
- На экране появляется большая надпись: **«ВНИМАНИЕ: ВОЗМОЖЕН ПОЖАР»**
- Появляется всплывающее предупреждение и звуковой сигнал (пока не подтверждено)
- Кнопка **«Acknowledge alarm»** подтверждает тревогу

### Наклон (акселерометр)
- Для наклона используются **только Y/Z**
- Статус:
  - **ВНИМАНИЕ** при \(|Y| или |Z| ≥ 25°\)
  - **ТРЕВОГА** при \(|Y| или |Z| ≥ 45°\)

### ОХРАНА (тумблер)
Когда включаешь **ОХРАНА**:
- панель “запоминает” текущие **Y/Z** как **норму** (baseline)
- дальше реагирует на отклонение от нормы:
  - предупреждение при \(\Delta ≥ 8°\)
  - тревога при \(\Delta ≥ 15°\)

## История и логи
- CSV файлы записываются в папку `data_logs/`
- имя файла: `sensors_YYYY-MM-DD.csv`

Если хочешь хранить логи на флешке/в другом месте — можно изменить `DATA_DIR` в `qt_serial_dashboard.py`.

## Если “ничего не работает”
- **NO DATA / НЕТ ДАННЫХ**:
  - проверь питание Arduino
  - проверь USB‑кабель (должен быть “data”, не только зарядка)
  - закрой Serial Monitor/Plotter
  - переподключи USB
- **Access is denied / PermissionError**:
  - порт занят (обычно Arduino IDE Serial Monitor/Plotter)
